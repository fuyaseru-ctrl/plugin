## 中身の決まり

- 実在の銘柄名・大株主の名前は出さない（〇〇〇〇）。ChatGPT の画面は絵で描いた見本（隅に「画面はイメージです」）
- 答えを取りに行くサイトの名前は、声にも字幕にも出さない（画面の絵だけ）
- 大株主の動画は、答えの判断の言葉（打診買い・〇〇円になったら狙う）と買う値を映さない（灰色の帯）。「判断は3つの段階」「物差しは大株主の買値との差」と言う
- 逆指値の動画は、証券会社の名前とアプリの名前を出さない（〇〇証券・〇〇アプリ）。講師のお名前は出さず「講師」と言う。答えの判断の行は映さない（灰色の帯）
- 会話引継ぎの動画は、相談の中身を〇〇で伏せ（持ち株〇〇〇〇・買値〇,〇〇〇円）、判断の行は映さない（灰色の帯）。引継ぎの1枚・受け取りの答え・次に聞くと良いこと3つは、2026-11-25 の本物のプラグインの答えの形に合わせた。入力欄の印は緑・送った後の印は赤（本物どおり）
- 逆指値の動画の答えの形（10社の縦の一覧・スマホかパソコンかの問い・押す順10行・銘柄の答え・次に聞くと良いこと）は、2026-11-24 に本物のプラグインを ChatGPT で動かした答えに合わせた。押す順は 2026-11-22 時点の各社の公式の手順＝画面が変わったら直す
- 新NISA枠の動画は、銘柄・金額・日付を〇〇で伏せ（〇〇〇〇・〇〇万円・〇月〇日）、置き場所の判断の行は映さない（灰色の帯）。締めの日などの日付は声にも字幕にも出さない（来年に見ても古くならないため・日付はプラグインがその年の物で答える）。止まり方5つ・NISA作戦メモの8つの見出し・次に聞くと良いこと3つは、2026-11-28 の本物のプラグインの答えと指示書の形に合わせた。「ほどく一言」の例は、金融庁のNISAのページの決まり（売った株の生涯の枠は、買った値段の分だけ翌年に戻る）
- 年末の節税売りの動画は、銘柄・金額・日付を〇〇で伏せ、売る株の判断の行は映さない（灰色の帯）。締めの日などの日付は声にも字幕にも出さない（新NISA枠と同じ）。戻る税の例（今年の利益30万円・損20万円→約4万円＝20万円×20.315%）は、指示書の決まり（戻る税は今年の利益まで×20.315%）どおりの計算で、2026-11-28 の本物のプラグインの試しの答えと同じ例。結論＋考え方の流れ5つ・節税売りメモの8つの見出し・次に聞くと良いこと3つ・締めの1行は、本物の答えと指示書の形に合わせた
- 注意書きのカードは入れない（案内ページの下に出ているため）
- 「フヤセルAI」の読み＝Kozy・Hatake・Otani・Hanano は「フ ヤセルエーアイ」、Satomi は「フ ヤセル エーアイ」（声によって言い方が変わるため、原稿の読みに書く）
- 新NISA枠の「次の1手」の読みは、漢字の「一手」と書く（ひらがなの「いって」だと音の高さが違った・Hanano）
- ★同じ書き方でも、読ませるたびに言い方が少し変わる（年末の節税売りの最後の「フヤセルAI」が「フ」と「ヤセル」の間で切れて聞こえた）＝まとめの場面だけ同じ書き方で3回・別の書き方で2回読ませて聞き比べ、1つを選んで差し替えた（`試し読み_フヤセルAI/声_1/`）

## 作り方フォルダの中身

| ファイル | 何か |
|---|---|
| `原稿_案4.txt`（逆指値は `原稿_案1.txt`） | 最後の原稿。1行＝字幕1枚・「表示｜読み」＝読み方・空行＝間・# の行は読まない |
| `原稿_*だけ.txt`・`原稿_案2.txt` | 場面ごとに読み直した時の原稿（声のフォルダの元） |
| `声_<声の名前>_<案>/` | ElevenLabs で読んだ声（`声.mp3`）と字幕ごとの時刻（`時刻.json`） |
| `build_timeline_v*.py` | 場面ごとに声を選んで切り、間を入れてつなぐ → `timeline_v*.json` と `声_間入り_v*.wav` |
| `video_v*.html` | 画面の元（t 秒目の絵を描く）。`assets/huya.png` を使う |
| `render_v*.js` | 画面の元を1コマずつ撮って、音なしの動画にする（画面なしの Chrome） |
| `mk_bgm.py` | 後ろのピアノを一から作る（人の曲を使わない） |
| `mix_v*.py` | 声とピアノを混ぜて、音の大きさを -15.3 LUFS にそろえる |
| `range_server.py` | 画面の元を配る、このパソコンの中だけの小さな配り口 |

## 作り直す順番（作り方フォルダの中で）

1. `py build_timeline_v*.py`（`声_間入り_v*.wav` がもうあると止まる＝別の名前で作り直す）
2. `py range_server.py <ポート> .` を別に立てる（`render_v*.js` の中のポートに合わせる）
3. `node render_v*.js video 下書き_v*_映像.mp4`
4. `py mk_bgm.py <長さの秒> BGM_v* A`（長さは `timeline_v*.json` の total）
5. `py mix_v*.py` → `下書き_v*.mp4`

- 会話引継ぎは、声も絵も1版＝時間割は `build_timeline_v1.py`（`timeline_v1.json`・`声_間入り_v1.wav`）、画面は `video_v1.html`・`render_v1.js`（作り方フォルダの中で `py range_server.py 47666 .`）、ピアノは `py mk_bgm.py 115.02 BGM_v1 A`、混ぜるのは `mix_v1.py`。声は通し読み1本（`声_Otani_案1/`）だけ。`render_v1.js stills <フォルダ> <秒,秒>` は、撮るたびに字幕の帯と絵のかぶり・画面の外へのはみ出しも数える
- 新NISA枠は、通し読み（`声_Hanano_案1/`）のうち「NISA作戦メモ」と「まとめ」の場面だけを `原稿_案2_*だけ.txt` で読み直して差し替えた＝時間割は `build_timeline_v2.py`（`timeline_v2.json`・`声_間入り_v2.wav`）、画面は `video_v2.html`・`render_v2.js`（作り方フォルダの中で `py range_server.py 47666 .`）、ピアノは `py mk_bgm.py 131.34 BGM_v2 A`、混ぜるのは `mix_v2.py`。★Hanano の声は届いたままで小さい（-31.4 LUFS）ため、`mix_v2.py` は声だけ先に前の回の声の大きさ（-18.4）まで上げ、軽く抑えてから混ぜる
- 年末の節税売りは、通し読み（`声_Hanano_案1/`）のうち「まとめ」の場面だけを `試し読み_フヤセルAI/原稿_1.txt` の声に差し替えた＝時間割は `build_timeline_v2.py`（`timeline_v2.json`・`声_間入り_v2.wav`）、画面は `video_v2.html`・`render_v2.js`（作り方フォルダの中で `py range_server.py 47666 .`）、ピアノは `py mk_bgm.py 131.71 BGM_v2 A`、混ぜるのは `mix_v2.py`（新NISA枠と同じく、声だけ先に上げてから混ぜる）
- ★会話を上へ送る動き（画面の元の scroll）は、新NISA枠の `video_v2.html` で直した＝前の4本の画面の元は、送る途中が一瞬で跳ぶ形のまま（作り直す時は新NISA枠の形を使う）
- 逆指値は、声と音楽は1版のまま絵だけ2版に直した＝時間割は `build_timeline_v1.py`（`timeline_v1.json`・`声_間入り_v1.wav`）、画面は `video_v2.html`・`render_v2.js`（ポート 47633）、ピアノは `py mk_bgm.py 108.91 BGM_v1 A`、混ぜるのは `mix_v2.py`。声は通し読み1本（`声_Hatake_案1/`）だけ

- 道具の中の ffmpeg と playwright-core の場所は、作ったパソコンの決まった場所を指しています。別のパソコンで使う時は書き換えてください
- 声を読み直す時は、ElevenLabs（モデル Eleven v4）で、直したい場面だけ読み直すとクレジットの節約になります
